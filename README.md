# Костыль 1С

**Костыль 1С** — программа, которая делит CSV-таблицу, выгруженную из 1С, на отдельные
таблицы по подразделениям и сохраняет их в форматах CSV, XLS (Excel, `.xlsx`), PDF и HTML.

**Автор:** Горшков Сергей Владимирович ([nookbat.ru](https://nookbat.ru/))

![Костыль 1С](build/icon.png)

## Формат входного файла

- CSV, разделитель `;`, кодировка UTF-8 (с BOM или без; файлы в Windows-1251 тоже читаются).
- Строки 1–2 — информационные, в обработке не участвуют.
- Строка 3 — шапка таблицы.
- Строки 4 и далее — сотрудники. **3-й столбец** — подразделение (номер и название).

Пример — [`testdata/sample.csv`](testdata/sample.csv).

## Как пользоваться

1. «Открыть CSV…» (или перетащить файл в окно, или передать путь аргументом:
   `kostil1c файл.csv`).
2. Программа показывает список подразделений (полное название) и число сотрудников в каждом.
   По умолчанию отмечены все; галочки снимаются для каждого подразделения отдельно
   (по клику на флажок или на название). Есть поиск и кнопки «Выбрать все» / «Снять все»
   (действуют на подразделения, найденные поиском). Внизу — счётчик выбранных подразделений.
3. «Экспорт…» → отметить один или несколько форматов (CSV, XLS, PDF, HTML), выбрать папку,
   нажать **ЗАПУСК**.

Для каждого отмеченного подразделения в выбранной папке создаётся по файлу на каждый формат.
Имя файла — название подразделения (символы, недопустимые в именах файлов Windows/Linux,
заменяются на `_`; имена длиннее 100 символов обрезаются; совпавшие имена получают суффикс
` (2)`, ` (3)`…). В каждом файле — шапка исходной таблицы и все строки сотрудников этого
подразделения целиком (все столбцы). Опция «Добавлять информационные строки (1–2)» переносит
в каждый файл первые две строки исходного файла (в CSV — как есть, в XLS — первыми строками
листа, в PDF/HTML — подзаголовком).

| Формат | Что получается |
| ------ | -------------- |
| CSV    | `;`, UTF-8 (BOM — как в исходном файле), структура как у исходного файла |
| XLS    | Книга Excel `.xlsx`: шапка выделена, закреплена, включён автофильтр |
| PDF    | Ширина столбцов — по содержимому (текст не обрезается и не переносится); альбомная A4, при широкой таблице — A3/A2 или нестандартная ширина листа; шапка повторяется на каждой странице, кириллица (DejaVu Sans) |
| HTML   | Одна страница с таблицей, годится для печати |

## Дистрибутивы

На странице [Releases](https://github.com/Serge-Nook/kostil1c/releases):

| Файл | Система |
| ---- | ------- |
| `Kostil1C-<версия>-x86_64.AppImage` | SteamOS и другие Linux (`chmod +x` и запустить) |
| `kostil1c_<версия>_amd64.deb` | Astra Linux 1.7 / 1.8, Debian, Ubuntu (`sudo apt install ./kostil1c_*.deb`) |
| `Kostil1C-<версия>-Setup.exe` | Windows 10 / 11 x64 — установщик |
| `Kostil1C-<версия>-portable.exe` | Windows 10 / 11 x64 — без установки |

Linux-сборка делается в Debian 10 (glibc 2.28 — база Astra Linux 1.7), поэтому запускается на
Astra 1.7, 1.8 и более новых системах. Для работы нужен OpenGL (на Windows — драйвер видеокарты;
в виртуальной машине/RDP без 3D-ускорения программа может не запуститься).

## Сборка из исходников

Go 1.26+, компилятор C и библиотеки для [Fyne](https://fyne.io):

```bash
sudo apt install gcc pkg-config libgl1-mesa-dev xorg-dev
go run . testdata/sample.csv     # запуск
go test ./...                    # тесты
```

Все дистрибутивы (нужны Docker, `gcc-mingw-w64-x86-64`, `nsis`):

```bash
./packaging/release.sh           # → dist/
```

- `packaging/build-linux.sh` — бинарник, `.deb`, `.AppImage` (вызывается внутри `debian:buster`);
- `packaging/build-windows.sh` — `portable.exe` и установщик NSIS (статическая линковка MinGW).
